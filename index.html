01
分而治之Divide
拆认知通路Split cognition
数值与图形是两条认知通路：指标 Agent 按固定口径归纳波动率、趋势、量能；识图 Agent 把握 K 线结构与通道形态。拆给不同 Agent，降低单模型的注意力分散，每份结论都保留可追溯的原始依据。Numbers and charts are two cognitive paths: one agent normalizes metrics, the other reads chart structure. Splitting them cuts attention dilution and keeps every conclusion traceable.
02
强制交叉核验Cross-check
防幻觉工程化Engineered anti-hallucination
识图 Agent 的每个视觉结论都必须锚定结构化数值复核，图文冲突时以数值为准并显式标注。防幻觉不靠提示词祈祷，而是做成一条可执行的工程约束——这是最值得抄走的一招。Every visual claim must be re-anchored to structured numbers; on conflict, numbers win and it shows. Anti-hallucination as an executable constraint, not a prompt-time prayer.

LLM 机制：训练流程 × 运作流程LLM Mechanism: Training × Inference

左：训练阶段如何构建大模型；右：上线后模型如何对外提供服务。两条流程最终汇向「大语言模型」这一核心。Left: how training builds the model; right: how inference serves it. Both converge on the LLM core.

附图 · LLM 训练流程（纵向）与运作流程（横向）Fig · LLM training (vertical) vs inference (horizontal)
训练三步走Training · 3 steps
预训练习得通识、后训练对齐指令、强化学习对齐人类偏好；蒸馏与量化负责「压缩」。Pre-training → post-training → RLHF; distillation & quantization compress the model.
运作三件套Inference · 3 parts
Prompt → 分词器 → Token →（RAG 检索增强）→ 模型 → 生成结果。RAG 并非必经路径，却将模型从「仅依赖训练数据」拓展为「可检索实时信息」。Prompt → tokenizer → Token → (RAG) → model → output. RAG is optional but unlocks real-time retrieval.
三种模型形态Three model forms
稠密（Dense）：全部参数参与每次推理。稀疏（Sparse）/ 混合专家（MoE）：按需激活部分参数，省算力但调度复杂。Dense: all params active. Sparse / MoE: activate on demand — cheaper but harder to schedule.
一切训练与推理，最终都汇向「大语言模型」这一核心。All training and inference converge on one core: the LLM.
